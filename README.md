# Inventory Rampage Mod

Модифицированный **Inventory Rampager** для Magic Rampage.

**Репозиторий:** https://github.com/nefix148-ux/inventory-rampage-mod

## Что добавлено

- **Чёрный список** предметов / тоников / классов / элементов + возможность убирать
- **Диапазоны min–max**: урон, броня, скорость, импульс прыжка, радиус взрыва, скорость снаряда
- UI-панель для управления
- Авто-хук `Worker.postMessage` — фильтры подмешиваются сами
- Воркер совместим с оригинальным форматом сообщений приложения

## Структура

```
src/
  find-good-set.worker.clean.js   ← новый воркер
  find-set-ui-overlay.js          ← UI + авто-хук
docs/
  NOTES.md
  INTEGRATION.md
  REBUILD_APK.md                  ← пошаговая пересборка APK
extracted/
```
